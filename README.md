# KisanConnect UI

Create a modern, responsive, visually attractive frontend for a college mini-project called "KisanSetu".

PROJECT DESCRIPTION:

KisanSetu is a digital agricultural support platform designed primarily for small and marginal farmers. The platform connects farmers with local seed vendors, agricultural equipment providers, and agricultural workers. It also provides personalized seed recommendations, a DEMO subsidy/discount system, order management, an AI-assisted farmer chatbot, and an admin/government-style analytics dashboard.

IMPORTANT:

This is strictly a COLLEGE MINI-PROJECT / PROTOTYPE.

Do NOT claim or imply that the application is officially connected to the Indian Government, Aadhaar, real government subsidy schemes, real payment gateways, or real 10-minute delivery services.

All subsidy, payment, analytics, vendor, and delivery information must be clearly labelled as DEMO DATA / PROTOTYPE.

DESIGN STYLE:

- Modern and clean agricultural theme

- Primary colors: natural green, light green, earthy brown, white

- Use subtle farming illustrations, crop icons, seed icons, tractor icons, and agricultural visuals

- Friendly and easy-to-use interface for farmers

- Responsive design for mobile, tablet, and desktop

- Use modern cards, rounded corners, soft shadows, and smooth hover effects

- Keep the interface simple and accessible for users with limited technical knowledge

- Use readable fonts and large buttons
